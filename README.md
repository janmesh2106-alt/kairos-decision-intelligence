# KAIROS// — Decision Intelligence Platform

An interactive decision intelligence engine built with TypeScript, Vite, and Node.js. KAIROS// structures complex analytical workflows, evaluates trade-offs, and delivers actionable decision insights.

---

## Architecture & Tech Stack

- **Frontend:** TypeScript, Vite, HTML5/CSS3 (`src/`, `index.html`)
- **Backend / API Server:** Node.js & TypeScript (`server.ts`)
- **Configuration:** Vite (`vite.config.ts`), TypeScript (`tsconfig.json`)
